    Environnement : Oracle Linux 8 — Base ELIORA

    1. Préparation des disques LVM

    # Vérifier les disques disponibles
lsblk
df -h
fdisk -l /dev/sdb
fdisk -l /dev/sda

# Vérifier les groupes de volumes existants
vgs

# Créer le groupe de volumes
vgcreate vg_oracle /dev/sda
vgs

# Créer les volumes logiques
lvs
lvcreate -L 30G -n lv_oracle   vg_oracle
lvcreate -L 50G -n lv_oradata  vg_oracle
lvcreate -L 10G -n lv_orarman  vg_oracle
lvcreate -L 10G -n lv_oraarch  vg_oracle

# Formater en ext4
mkfs.ext4 -m 0 /dev/vg_oracle/lv_oracle
mkfs.ext4 -m 0 /dev/vg_oracle/lv_oradata
mkfs.ext4 -m 0 /dev/vg_oracle/lv_orarman
mkfs.ext4 -m 0 /dev/vg_oracle/lv_oraarch

    Montage permanent — /etc/fstab

    vi /etc/fstab

    Ajouter les lignes suivantes :

    /dev/mapper/vg_oracle-lv_oracle  /oracle   ext4  defaults  0 0
/dev/mapper/vg_oracle-lv_oradata /oradata  ext4  defaults  0 0
/dev/mapper/vg_oracle-lv_orarman /orarman  ext4  defaults  0 0
/dev/mapper/vg_oracle-lv_oraarch /oraarch  ext4  defaults  0 0

    # Monter tous les systèmes de fichiers
mount -a

    2. Configuration système

    Fichier /etc/hosts

    vi /etc/hosts

    172.20.10.12  oravm19tony

    Désactiver SELinux

    vi /etc/selinux/config

    Remplacer : 

    SELINUX=enforcing
    par : 
    SELINUX=permissive

    Appliquer immédiatement sans reboot :

    setenforce Permissive

    3. Prérequis Oracle

    # Mise à jour du système
dnf update -y

# Installation du paquet preinstall Oracle 19c
# Configure automatiquement : kernel params, limites, groupes oinstall/dba/...
dnf install oracle-database-preinstall-19c -y

# Dépendances complémentaires si nécessaire
dnf install compat-libcap1 -y
dnf install libcap libcap-ng -y

# Créer les répertoires Oracle
mkdir -p /opt/oracle/product/19.0.0/dbhome_1
mkdir -p /home/oracle/oraInventory

# Droits
chown -R oracle:oinstall /opt/oracle /home/oracle/oraInventory
chmod -R 775 /opt/oracle

# Placer le binaire Oracle ici avant installation
mkdir -p /sources/oracle/

    4. Variables d'environnement

    Fichier ~/.bash_profile (utilisateur oracle)

    vi /home/oracle/.bash_profile

    # .bash_profile

if [ -f ~/.bashrc ]; then
    . ~/.bashrc
fi

# Oracle Settings
export TMP=/tmp
export TMPDIR=$TMP

export ORACLE_HOSTNAME=oravm19tony
export ORACLE_UNQNAME=ELIORA
export ORACLE_SID=ELIORA

export ORACLE_BASE=/opt/oracle
export ORACLE_HOME=$ORACLE_BASE/product/19.0.0/dbhome_1
export ORA_INVENTORY=/home/oracle/oraInventory

export PATH=/usr/sbin:/usr/local/bin:$PATH
export PATH=$ORACLE_HOME/bin:$PATH

export LD_LIBRARY_PATH=$ORACLE_HOME/lib:/lib:/usr/lib
export CLASSPATH=$ORACLE_HOME/jlib:$ORACLE_HOME/rdbms/jlib

export NLS_LANG=AMERICAN_AMERICA.AL32UTF8
export NLS_DATE_FORMAT='DD-MM-YYYY HH24:MI:SS'

clear
echo -e "\n====== Variables Oracle ======\n"
env | grep ORACLE
echo -e "\n==============================\n"

    # Recharger le profil
source /home/oracle/.bash_profile

# Vérifier
echo $ORACLE_BASE
echo $ORACLE_HOME
echo $ORACLE_SID

    5. Installation du binaire Oracle 19c

    # Se connecter en oracle
su - oracle

# Décompresser le binaire dans ORACLE_HOME
cd $ORACLE_HOME
unzip -oq /sources/oracle/Oracle_Database_19.3.0.zip

# Contournement pour OL8 (Oracle vérifie OL7 par défaut)
export CV_ASSUME_DISTID=OL7

# Lancer l'installateur graphique
./runInstaller

    Note : L'installateur graphique (runInstaller) nécessite un affichage X11 ou une session graphique. En mode silencieux, utiliser l'option -silent.

    Scripts root à exécuter après l'installation

    # En tant que root
/opt/oracle/product/19.0.0/dbhome_1/root.sh

    Vérification post-installation

    sqlplus / as sysdba
startup
SELECT STATUS FROM V$INSTANCE;
EXIT;

    6. Démarrage automatique au boot

    Modifier /etc/oratab

    # En root
vi /etc/oratab

    Changer N en Y pour ELIORA :

    ELIORA:/opt/oracle/product/19.0.0/dbhome_1:Y

    Activer dbstart au boot via rc.local

    vi /etc/rc.d/rc.local

    Ajouter :

    su - oracle -c "/opt/oracle/product/19.0.0/dbhome_1/bin/dbstart $ORACLE_HOME"

    # Rendre rc.local exécutable
chmod +x /etc/rc.d/rc.local

    Alternative : Utiliser un service systemd /etc/systemd/system/oracle-db-start.service pour un démarrage plus propre.

    7. Création des répertoires et liens symboliques

    # En tant qu'oracle
su - oracle

# Répertoires dans /opt/oracle/oradata
mkdir -p /opt/oracle/oradata/ELIORA/base
mkdir -p /opt/oracle/oradata/ELIORA/adump
mkdir -p /opt/oracle/oradata/ELIORA/cdump
mkdir -p /opt/oracle/oradata/ELIORA/udump
mkdir -p /opt/oracle/oradata/ELIORA/adhoc
mkdir -p /opt/oracle/oradata/ELIORA/conf
mkdir -p /opt/oracle/oradata/ELIORA/create
mkdir -p /opt/oracle/oradata/ELIORA/customize
mkdir -p /opt/oracle/oradata/ELIORA/logbook
mkdir -p /opt/oracle/oradata/ELIORA/tmp
mkdir -p /opt/oracle/oradata/ELIORA/wallet
mkdir -p /opt/oracle/oradata/ELIORA/diag

# Répertoires dans /opt/oracle/orasave
mkdir -p /opt/oracle/orasave/ELIORA/arch
mkdir -p /opt/oracle/orasave/ELIORA/echange
mkdir -p /opt/oracle/orasave/ELIORA/exp
mkdir -p /opt/oracle/orasave/ELIORA/fra
mkdir -p /opt/oracle/orasave/ELIORA/mirror
mkdir -p /opt/oracle/orasave/ELIORA/rman

# Droits
chown -R oracle:oinstall /opt/oracle/oradata/ELIORA
chown -R oracle:oinstall /opt/oracle/orasave/ELIORA
chmod -R 750 /opt/oracle/oradata/ELIORA
chmod -R 750 /opt/oracle/orasave/ELIORA

# Création des liens symboliques
cd /opt/oracle/oradata/ELIORA

ln -s /opt/oracle/orasave/ELIORA/arch    arch
ln -s /opt/oracle/orasave/ELIORA/echange echange
ln -s /opt/oracle/orasave/ELIORA/exp     exp
ln -s /opt/oracle/orasave/ELIORA/fra     fra
ln -s /opt/oracle/orasave/ELIORA/mirror  mirror
ln -s /opt/oracle/orasave/ELIORA/rman    rman

# Vérifier
ll /opt/oracle/oradata/ELIORA

    8. Création de la base via DBCA

    # En tant qu'oracle
su - oracle

# Lancer DBCA en mode graphique
dbca

    Format des archives : ELIORA_%t_%s_%r.arc

    9. Structure des fichiers de contrôle et redo logs

    Fichiers de contrôle (multiplexés)

    Fichier Emplacement
    control01.ctl /opt/oracle/oradata/ELIORA/base/ELIORA/
    control02.ctl /opt/oracle/orasave/ELIORA/mirror/ELIORA/

    Redo logs (multiplexés — 3 groupes x 2 membres)

    Groupe Membre A Membre B (miroir)
    Group 1 /opt/oracle/oradata/ELIORA/base/ELIORA/redo01_01.rdo /opt/oracle/orasave/ELIORA/mirror/ELIORA/redo01_02.rdo
    Group 2 /opt/oracle/oradata/ELIORA/base/ELIORA/redo02_01.rdo /opt/oracle/orasave/ELIORA/mirror/ELIORA/redo02_02.rdo
    Group 3 /opt/oracle/oradata/ELIORA/base/ELIORA/redo03_01.rdo /opt/oracle/orasave/ELIORA/mirror/ELIORA/redo03_02.rdo
