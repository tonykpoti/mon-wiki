    Guide : Créer son Wiki Personnel avec GitHub Pages + MkDocs

    Accessible partout dans le monde — 100% gratuit

    Résultat final : https://tonpseudo.github.io/mon-wiki/
    Durée estimée : 30 à 45 minutes

    Sommaire

    1. Créer un compte GitHub
    2. Installer Git sur Windows
    3. Installer Python et MkDocs
    4. Créer le projet wiki en local
    5. Ajouter tes fichiers Markdown
    6. Publier sur GitHub Pages
    7. Mettre à jour le wiki au quotidien

    1. Créer un compte GitHub

    1. Va sur https://github.com
    2. Clique sur Sign up
    3. Remplis :
    4. Email : ton email personnel
    5. Password : mot de passe fort
    6. Username : choisis un pseudo (ex: tonykpoti) — ce sera dans ton URL
    7. Valide ton email (GitHub envoie un code)
    8. Sur la page de démarrage, clique Skip (pas besoin de configurer plus)

    ⚠️ Retiens bien ton username GitHub — il apparaîtra dans l'URL de ton wiki.

    2. Installer Git sur Windows

    Téléchargement

    1. Va sur https://git-scm.com/download/win
    2. Le téléchargement démarre automatiquement (64-bit)
    3. Lance l'installateur .exe

    Installation (options importantes)

    - "Select Components" → laisser les options par défaut
- "Default editor" → choisir "Visual Studio Code" si installé, sinon "Notepad++"
- "PATH environment" → choisir "Git from the command line and also from 3rd-party software"
- Tout le reste → Next > Next > Install

    Vérification

    Ouvre Git Bash (cherche "Git Bash" dans le menu démarrer) :

    git --version
# Résultat attendu : git version 2.x.x

    Configuration initiale Git

    git config --global user.name "Tony KPOTI"
git config --global user.email "ton@email.com"

    3. Installer Python et MkDocs

    Installer Python

    1. Va sur https://www.python.org/downloads/
    2. Clique Download Python 3.x.x
    3. Lance l'installateur
    4. ⚠️ IMPORTANT : Cocher "Add Python to PATH" avant de cliquer Install

    Vérification Python

    Ouvre cmd (touche Windows + R, taper cmd) :

    python --version
# Résultat attendu : Python 3.x.x

pip --version
# Résultat attendu : pip 2x.x.x

    Installer MkDocs et le thème Material

    pip install mkdocs mkdocs-material

    Vérification MkDocs

    mkdocs --version
# Résultat attendu : mkdocs, version 1.x.x

    4. Créer le projet wiki en local

    Créer le dossier du projet

    Dans cmd ou Git Bash :

    # Aller dans tes Documents (ou l'endroit de ton choix)
cd C:\Users\TonNom\Documents

# Créer le projet MkDocs
mkdocs new mon-wiki
cd mon-wiki

    Structure créée automatiquement

    mon-wiki/
├── docs/
│   └── index.md       ← page d'accueil de ton wiki
└── mkdocs.yml         ← fichier de configuration

    Configurer mkdocs.yml

    Ouvre mkdocs.yml avec VS Code ou Notepad++ et remplace tout le contenu par :

    site_name: Wiki Tony KPOTI
site_url: https://tonpseudo.github.io/mon-wiki/
site_description: Documentation personnelle DBA Oracle & PostgreSQL
site_author: Antoine Koffi KPOTI

theme:
  name: material
  language: fr
  palette:
    primary: indigo
    accent: blue
  features:
    - navigation.tabs
    - navigation.sections
    - navigation.top
    - search.highlight
    - content.code.copy

nav:
  - Accueil: index.md
  - Oracle:
    - Data Guard 19c: oracle/dataguard-19c.md
  - PostgreSQL:
    - index: postgresql/index.md

markdown_extensions:
  - pymdownx.highlight:
      anchor_linenums: true
  - pymdownx.superfences
  - pymdownx.tabbed:
      alternate_style: true
  - admonition
  - pymdownx.details
  - tables

    ⚠️ Remplace tonpseudo par ton vrai username GitHub.

    Tester en local

    mkdocs serve

    Ouvre ton navigateur sur http://127.0.0.1:8000 — tu verras ton wiki en direct.
    Ctrl+C pour arrêter le serveur.

    5. Ajouter tes fichiers Markdown

    Organisation recommandée des dossiers

    docs/

├── oracle/

    └── maison-kpoti-app.md

    Créer les dossiers

    mkdir docs\oracle
mkdir docs\postgresql
mkdir docs\linux
mkdir docs\projets

    Copier ton guide Data Guard

    Copie le fichier oracle-dataguard-19c-eliora.md dans :

    docs/oracle/dataguard-19c.md

    6. Publier sur GitHub Pages

    Créer le dépôt GitHub

    1. Va sur https://github.com/new
    2. Repository name : mon-wiki
    3. Visibility : Public ✅ (obligatoire pour GitHub Pages gratuit)
    4. Ne cocher rien d'autre
    5. Clique Create repository

    Initialiser et pousser le projet

    Dans Git Bash, depuis le dossier mon-wiki :

    # Initialiser Git
git init

# Ajouter tous les fichiers
git add .

# Premier commit
git commit -m "Initial commit - wiki personnel"

# Connecter au dépôt GitHub (remplace tonpseudo)
git remote add origin https://github.com/tonpseudo/mon-wiki.git

# Pousser le code
git branch -M main
git push -u origin main

    GitHub va te demander ton username et un token (pas le mot de passe).
    Pour générer le token : GitHub > Settings > Developer settings > Personal access tokens > Generate new token (classic) — cocher repo — copier le token.

    Déployer sur GitHub Pages avec MkDocs

    # Cette commande construit et publie le wiki en une seule fois
mkdocs gh-deploy

    MkDocs va : 1. Construire le site HTML 2. Créer une branche gh-pages sur GitHub 3. Y pousser le site automatiquement

    Activer GitHub Pages

    1. Va sur ton dépôt GitHub : https://github.com/tonpseudo/mon-wiki
    2. Clique Settings > Pages (menu gauche)
    3. Source : Deploy from a branch
    4. Branch : gh-pages / (root)
    5. Clique Save

    ⏳ Attendre 2-3 minutes, puis ton wiki est accessible sur :

    https://tonpseudo.github.io/mon-wiki/

    7. Mettre à jour le wiki au quotidien

    Workflow simple pour ajouter ou modifier une doc

    # 1. Aller dans le dossier du projet
cd C:\Users\TonNom\Documents\mon-wiki

# 2. Ajouter ou modifier un fichier .md dans docs/

# 3. Tester en local (optionnel)
mkdocs serve

# 4. Sauvegarder et publier
git add .
git commit -m "Ajout doc : RMAN backup"
git push
mkdocs gh-deploy

    En résumé — les 3 commandes à retenir

    Commande Rôle
    mkdocs serve Prévisualiser en local
    git add . && git commit -m "message" && git push Sauvegarder le code source
    mkdocs gh-deploy Publier la mise à jour en ligne
